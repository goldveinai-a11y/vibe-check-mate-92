# Цена Single Report → $1.99

## 1. Stripe

Вместо ручной пересборки price-объектов используется штатный механизм платформы: создание цены с тем же ID `vibecheck_single` и суммой 199 центов. Платформа создаёт новый Price, переносит на него lookup key `vibecheck_single` и выводит старый из обращения. Прошлые платежи остаются привязаны к старому Price.

Делается в тестовой среде; на live каталог синхронизируется при публикации проекта (ID — ключ синхронизации), поэтому после правок нужно нажать Publish.

Код менять не нужно: `createCheckoutSession` резолвит цену по lookup key.

## 2. Код — где цена написана руками

Меняются только цифры, больше ничего — ни текст, ни вёрстка, ни комментарии, ни логика.

- `src/routes/paywall.$id.tsx`, тариф `single`: `price: "$4"` → `"$1"`, `priceValue: 4.99` → `1.99`, в CTA `Get Only This Report - $4.99` → `$1.99`.
- `src/components/StickyUnlockBar.tsx`: `$4.99` → `$1.99`.

Тарифы Monthly и Yearly не трогаем. Ничего больше в этих файлах не редактируется.

## 3. Что проверено по коду и правок не требует

- Скидка WINGMAN20 нигде числом не посчитана: в UI это только текст «20% off», сама скидка применяется купоном на стороне Stripe.
- Маркетинговые страницы (`/`, `/example`, `/science`, `/vs/$slug`), FAQ, Terms, Refund цен не содержат — там формулировка «цена показана при оформлении».
- Сравнения «дешевле на X / экономия Y%» относятся только к годовому тарифу (`SAVE 67%`, `vs $9.99/mo`) — от цены Single не зависят.
- Winback-попап цену числом не выводит: это баннер с текстом про 20%, скидка применяется купоном.

## Замечания — только список, ничего из этого не делаю

- `StickyUnlockBar.tsx` рядом с ценой показывает зачёркнутый якорь `$9.99`. После смены на $1.99 это выглядит как скидка 80%. Оставляю как есть.
- Monthly остаётся с первым платежом $4.99. Раньше он был равен Single, теперь дороже на входе в 2.5 раза — часть покупателей уйдёт в Single. Не меняю.
- В `src/lib/vibecheck-chat.server.ts` комментарий упоминает «one-time $4.99» — станет неактуальным. Не трогаю, это комментарий.

## Проверка

Пройти путь результат → пейволл → Single → Stripe Checkout и убедиться, что на пейволле и в Checkout стоит $1.99.
